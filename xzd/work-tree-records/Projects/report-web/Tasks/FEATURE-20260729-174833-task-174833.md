## Architecture
1. **Designer UI**：Handsontable 表头多选 -> `contextMenu` hide/show -> hiddenRows/hiddenColumns plugin。
2. **State**：插件运行索引通过视觉/物理转换写入当前 sheet 的 `globalSettings`；最终保存由 `saveToStore` 或 `handleSavedSheetsSchema` 再次同步，数据格式是 `hiddenRows: number[]`、`hiddenColumns: number[]`。
3. **Preview**：加载全局配置（同时兼容旧 cell 标记）作为 persistent base；树和筛选不直接 show/hide，而是把自己的层交给 coordinator，避免展开树/清除筛选意外揭示设计器隐藏行列。
4. **Print**：以全局及运行时隐藏状态计算隐藏集合；行维度从分页扫描、行高、表体输出中剔除，列维度压缩分页范围、PDF body/widths/colSpan，再将浮动图逻辑锚点映射到物理列。

# Implementation Plan

## Goal
在报表设计器中支持按行/列头隐藏和恢复轴，并将该状态按 sheet 持久化、在预览/筛选/树/打印/批量打印中一致地生效。

## Scope
- 以当前代码和生命周期交接中“报表设计器行列隐藏”为需求基线：隐藏状态使用 `globalSettings.hiddenRows`、`globalSettings.hiddenColumns` 的索引数组存储，并兼容旧单元格 `rowHidden`/`colHidden` 标记。
- 覆盖设计器操作、保存/加载、预览叠加可见性、PDF 生成和批量打印合并；同时修复当前预览连续多个筛选范围会丢失先前筛选隐藏集合的回归风险。

## Non-goals
- 不实现任意单元格级别的隐藏，也不继续写入旧 `rowHidden`/`colHidden` 元数据。
- 不允许通过隐藏绕过合并单元格约束；合并区域需先取消合并。
- 不改变筛选算法、树结构算法、报表数据排序语义或新增独立导出格式；仅使既有链路正确消费隐藏状态。
