# report-web 5大业务模块多语言 (i18n) 清单总览

本索引汇总了 `report-web` 前端项目中全部 5 个业务类型（页面及其内部引用的全部组件）的国际化多语言词条。

> **规范原则**：
> 1. **扁平化 Key (Flat Identifier)**：小驼峰，纯语义，无点号，全局唯一。
> 2. **参数占位符规范 (Mustache / Double Braces)**：所有包含动态变量的词条统一使用双花括号包裹，如 `{{pageSize}}`、`{{remainCount}}`、`{{field}}`。
> 3. **业务解耦与独立语言包**：每个业务类型单独生成对应的多语言 JSON 字典，便于各页面按需动态加载。
> 4. **组件全覆盖**：已全面覆盖各业务页面内部组件及共享引用组件（如 `transferTable`, `printSetting`, `querySetModal`, `bindInfoField`, `catagoryTree` 等）。

## 快速使用说明

每个业务类型的独立 JSON 位于当前目录的 `i18n/` 文件夹下，可直接导入用于前端多语言框架（如 react-intl / vue-i18n / udp-ui 国际化平台）：

```typescript
// 示例：动态载入指定业务的多语言字典
import dataSourceZhCN from './i18n/DataSourceManager.json';
import dataSetZhCN from './i18n/DataSetManager.json';
import tableZhCN from './i18n/TableManager.json';
import printZhCN from './i18n/PrintManager.json';
import simpleTableZhCN from './i18n/SimpleTableManager.json';
```
