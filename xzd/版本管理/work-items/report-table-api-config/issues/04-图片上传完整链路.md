## What to build

单元格和浮动图片两处上传都能通过实例配置适配 URL、真实文件表单与响应结果，并正确串接图片地址查询及删除。复用 02 的图片辅助请求，不另建竞争实现。

## 验收条件

- [ ] 两处 Upload 均完成接入，浮动图片独立查询 service 同样覆盖。
- [ ] 请求转换接收并返回含真实 File/Blob 的 FormData，字段可增删改名，旧字段/文件不被 Upload 自动补回。
- [ ] 默认方法、headers、上传限制及原交互行为保留；新 URL 同源与通道限制生效。
- [ ] 成功结果适配为原消费者要求的文件标识，后续查询/删除使用同一实例配置。
- [ ] 异步转换、失败不重发、多实例交错操作有测试和浏览器验证证据。
- [ ] 预览浮动图片仍只消费已有 URL，不引入额外附件查询。
- [ ] 相关回归、审查及持久交接完成。
