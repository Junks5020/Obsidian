## What to build

集成已验收的功能任务，形成一份覆盖 36 项接口、默认兼容并可交付的组件实现。集成 owner 只处理合并与集成问题，业务缺陷按归属退回原 owner，不在此重写各模块。

## 验收条件

- [ ] 接口清单、配置类型、所有实际调用点和测试覆盖一致，重复入口无遗漏。
- [ ] 完整执行需求基线的 15 组验收；未通过/无法执行项明确记录，不勾选完成。
- [ ] 定向测试、包全量回归、类型检查、构建和浏览器关键路径分别有证据。
- [ ] 新上下文 Standards 与 Spec 两轴并行审查；均显式使用指定 DeepSeek 模型，结论分开记录。
- [ ] 父会话裁定审查发现，修复后复验；只读审查者不直接修改项目。
- [ ] 形成精确提交或差异交接、验证报告及剩余风险，原工作区已有锁文件修改不变。
- [ ] 不推送、不发包、不部署，合入原工作区前由父会话核对工作树状态和范围。
