# 03 — 辅助查询接口适配

相关：[[work-items/report-table-api-config/spec]] · [[work-items/report-table-api-config/协作开发计划]] · [[work-items/report-table-api-config/接口覆盖清单]] · [[00-版本总览]]

## What to build

接入方可定制数据集、查询条件、帮助、菜单与表达式辅助接口，在 UI 操作实际触发时使用所属实例配置；不同后端响应先适配回各接口契约，再执行原业务消费。

## 验收条件

- [ ] 覆盖清单中的辅助 service 及其实际调用方，包含重复查询字段入口。
- [ ] 固定 query 可改可删，自定义 URL 同名覆盖后再转换，删除不补回。
- [ ] 混合 query/请求数据分别替换，不改变原通道和表单编码。
- [ ] 数组请求与 `Code`、`Success`、直接结果等响应分别验证，不统一强制信封。
- [ ] 表达式字段树现有返回行为不借适配改变，转换仍按契约执行。
- [ ] 双实例调用归属、异步异常和默认兼容有行为验证。
- [ ] 不修改主 service、上传组件或冻结共享契约；测试、审查及交接证据完备。
