## What to build

接入方通过单个设计器实例的三项配置完成读取设计；未配置保持旧行为，已有读取执行器优先且新配置不参与。共享适配契约供后续主流程、查询和文件任务复用，本项仅完成读取设计的业务接入，不代替后续任务。

## 验收条件

- [x] 通过公开组件 props 和读取触发路径，验证 URL、请求转换、响应转换可分别配置。
- [x] 不传配置、空配置、配置其他接口时，默认读取请求及业务行为不变。
- [x] 请求转换完全替换；支持 Promise；无效返回或抛错不发送，响应转换失败不继续、不重发。
- [x] 同源校验、query 优先级、参数通道限制遵守已确认基线。
- [x] 读取执行器优先时，新 URL/转换均不参与；其他已有执行器不回归。
- [x] 两个实际组件实例使用不同配置，交错发起并完成读取，网络参数和消费归属不串用；不得仅用孤立适配器测试替代。
- [x] 共享契约支持后续单通道、混合参数与文件接入；不提前迁移其他业务接口。
- [x] 定向红绿测试、相关旧回归、类型检查有命令和结果；环境阻塞如实记录。
- [x] 新上下文审查完成，父会话验收后才解除 02/03 blocker。

## 测试 seam

已批准的公开配置与真实设计器读取调用边界；在外部请求边界记录发送内容并提供确定响应，不替换包内适配器来证明自己。复杂 UI 依赖可用既有测试夹具，但必须覆盖两个真实设计器实例的配置绑定和异步调用归属。
