## 不应混入的调用

- `design/TableDesign/components/customTable/service.ts` 返回静态示例，不是后端接口。
- `PreviewFloatImageLayer` 只展示后端已解析的图片 URL，不调用附件查询接口。不为它额外增加取数逻辑。
- `<img src>` 和字体等静态资源加载不同于本表业务 API；本需求不扩展为通用网络拦截器。
- 不改 `report-web` 应用层或其他包的独立业务 API。

## 实施前必须补齐的验证

- 在每项实际消费者边界建立默认响应样例和最小合法响应契约，尤其不要把未查明的数据结构凭名称猜成平台信封。
- 对 36 项逐一建立默认请求与响应处理特征测试，覆盖所有重复入口；未执行的格子不得标完成。
- 新增/移除接口时，对默认地址表、业务调用点、公开配置类型和测试清单做一致性校验；本次静态检索不能代替以后全链路验收。
