## 实现拓扑与隔离

判定为 **multi-seam**：主流程、辅助查询、图片上传存在可独立验证的契约与调用边界，但共享实例配置和请求适配基础必须先稳定。

证据与重点：

- `src/context/index.tsx` 按固定 namespace 保存共享状态；01 不得仅在该共享 store 加入 `apiConfig` 就声称实例隔离，必须验证真实组件调用链。
- `src/design/service.ts` 同时包含保存、预览、导入导出、图片查询/删除；其余部分统一交 02，不拆成并行写入者。
- 辅助查询分布在各自 service 与调用方；03 的修改范围必须显式排除图片上传组件。
- 两处 AntD Upload 不经过普通 service；04 单独拥有上传适配与浮动图片路径，但不得绕过 02 再实现一份图片查询/删除契约。
- 05 是集成与验收所有者，不在合并阶段重写各业务模块；模块缺陷退回其唯一写入者处理。
