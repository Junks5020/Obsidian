# 01 公开选区读取接口

Blocked by: none

相关：[[../spec]] · [[../../../research/2026-10-09-新版报表计算选区与数值能力答复]]

## Goal

在现有 `ReportTableMinApi` 上新增 `getSelectedRange()`，让宿主同步获取完整矩形选区。

## Acceptance

- [ ] B2:D6 返回 `{ startRow: 1, startCol: 1, endRow: 5, endCol: 3 }`。
- [ ] 反向选择、单格、整行、整列和全选具有明确边界。
- [ ] 无实例、无选择、无效坐标返回 `null`；只读状态可读。
- [ ] `ReportSelectedRange` 从组件包公开导出，原 API 行为保持。
- [ ] 使用说明和演示包含新 API，原三项问题答复同步更新。
- [ ] 针对性测试和组件构建通过；如有既有失败，单独报告。
