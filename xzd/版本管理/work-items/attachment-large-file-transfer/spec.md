# udp-ui 大文件附件传输规格

相关：[[00-版本总览]] · [[ng-design-附件术语表]] · [[ng-design-Agent工作流配置]] · [[ng-design-ADR-0001-附件权限分类块透传]] · [[ng-design-ADR-0002-附件权限补丁限定源码目录]] · [[research/2026-10-26-ng-design-udp-ui-大文件附件上传下载取消核查]]

## 问题与目标

当前上传先计算所有 1 MiB 文件块的 MD5 才检查并上传，取消在切块期间延迟且最后一块和全部缓存命中可能漏掉。默认下载完整文件到前端构造 Blob，缺少大文件自动切换。用户需要提前开始上传、立即看到取消反馈，并在大文件下载时交由浏览器处理。

原始现状依据 `ljx-6.5.2`、`udp-ui@6.520.285` 的源码与隔离探针。实施后各任务进展见下文；真实浏览器、后端清理和鉴权仍需按 05 验收，标签链接返回带水印文件的后端能力已由用户确认。

## 用户场景

1. 上传大文件时首批准备完即可传输，进度只反映已成功登记或上传的块。
2. 取消上传立即显示取消中，停止后续步骤，可能已写入后端时等待在途请求结束后清理，成功才移除。
3. 多文件上传中一个文件失败、取消或完成不影响其他文件。
4. 下载超过 100 MiB 的单文件时浏览器接管；权限、业务校验、文件名、记录和水印语义保持一致。
5. 小文件和大小未知沿用原路径；浏览器触发仅表示已发起下载。

## 实施决定

- 文件分块为 1 MiB，每批最多 10 块：准备和算 MD5、批量检查、登记缓存块、串行上传缺失块，完成一批后释放引用再处理下一批。多个文件保持现有并行。批内结果转换全局序号，不改变后端协议。
- 固定任务文件、会话、分类、业务参数和 `uCode`；全部块成功后才调用一次成功回调。读取、MD5、检查、登记或上传失败时停止该文件并反馈，其他文件继续。
- 用 UID 独立跟踪取消，修复表格附件和现代弹窗现有入口，不为其他形态新增按钮。点击立即进入取消中并禁用重复点击；异步操作前后及成功前检查取消。未可能写入时本地取消，可能写入时等待在途请求结束再按原会话清理。
- 清理失败保留该项、提示并允许重试取消，不恢复上传或伪报成功；不记录成功新增来源。组件卸载或切换会话后不得让旧回调写入新会话，必要时按原会话清理。
- 表格、表单直接下载及独立标签单文件严格大于 104857600 字节时获取链接由浏览器下载，不请求完整 ArrayBuffer、不构造文件 Blob、不更新前端进度。支持合法数字和数字字符串，未知或非法大小沿原路径；既有 `downloadMethod='1'` 继续有效。
- 保留逐条权限及下载前业务校验、来源/工作流会话、实例 `uCode`、水印、编辑标识、文件名和下载记录。链接无效或失败时提示，不回退完整文件流、不记录成功。水印大文件必须下载满足原要求的资源，不静默下载原件。
- 不增加调用方必填参数或改变公开 API 签名；必要 service 参数扩展保持可选兼容。提示沿用现有多语言机制；分块、批数及阈值使用内部常量。

## 测试与验收

使用可控异步替身测试请求顺序和参数、状态、进度、成功回调、清理次数、下载点击和记录；优先现有 Node/TypeScript 测试能力，不新增 Jest 基础设施，先验证用例能暴露旧问题。源码字符串检查不能代替行为测试。

覆盖 10+10+5、全未命中/全命中/部分命中、全局序号、尾块、各阶段失败、多文件；取消覆盖读块、检查、登记、上传、最后一块、缓存命中、重复和多文件取消、清理失败重试、会话切换；下载覆盖阈值前一字节、阈值、后一字节、150 MiB、未知值、权限/业务拒绝、链接失败、多选及水印。

最终需 udp-ui 构建和差异检查、真实浏览器与限速大文件、真实后端清理，以及权限、业务校验、文件名、下载记录和水印回归。模拟结果不代表真实浏览器或后端验收。

## 当前实施进展

用户更新要求：大文件直接由浏览器访问文件 GET，不再先请求下载链接。表格/表单前端已调整并通过模拟行为测试；直接下载无法携带 XHR 的自定义鉴权头，须真实环境验证。独立标签附件仍使用获取链接旧方案，已重新标为 needs-info，水印完整文件直连接口尚待确认；不能称 01–04 均已完成。详见 [[work-items/attachment-large-file-transfer/issues/04-label-download]]、[[work-items/attachment-large-file-transfer/issues/05-validation]]。

整体未完成：05 的真实浏览器/限速网络和取消后的后端文件块及附件记录清理尚待验收。本轮未提交、发包或部署。

## 范围和约束

仅修改 udp-ui 附件相关实现，不修改后端、udp-core、移动组件或 ZIP 流程；不承诺暂停续传、刷新后恢复或新增上传重试。后端若不能清理最后一块后的记录或提供标签水印直下 URL，记录集成阻塞，不擅改协议或伪报成功。提交、跨分支同步、发包和部署另行安排。
