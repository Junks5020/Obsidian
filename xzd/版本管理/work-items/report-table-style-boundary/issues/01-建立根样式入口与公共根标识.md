# 01 — 建立根样式入口与公共根标识

Parent: [[work-items/report-table-style-boundary/spec]]

**What to build:** 建立后续样式收口所需的唯一根入口和稳定 DOM 归属标识，保持现有样式加载与组件行为不变。

**Blocked by:** None — frontier

**Status:** resolved

## Scope

- 新增 `packages/@newgrand/udp-report-table/src/style.less`，先建立 Shared、Design、Report Preview、Data Preview、Overlay / Portal 五个区段骨架。
- 让公共组件消费链自动加载根样式一次；业务应用继续只导入组件，不新增显式样式入口要求。
- `DesignReportTable` 根节点增加 `.udp-report-table.udp-report-table--design`。
- `ReportTable` 按 `mode` 增加 `.udp-report-table--report-preview` 或 `.udp-report-table--data-preview`，同时始终带 `.udp-report-table`。
- 保留原有 `className` 合并语义和内部 DOM 类名；四个根标识不能被调用方传入的类覆盖。
- 本 ticket 不迁移或删除局部 Less，不调整现有规则内容。

## Acceptance

- [x] 两个公共根组件在各模式下输出正确且稳定的根标识。
- [x] 根 `style.less` 由公共消费链自动加载且不会因嵌套子组件重复引入。
- [x] 调用方原有 `className` 仍生效，公开 props/events/types 不变。
- [x] 当前设计态、报表预览和数据预览的视觉与交互无变化。
- [x] 新增 `node:test` 边界断言覆盖根标识和自动入口。
- [x] 聚焦测试、TypeScript 检查、包构建和 `git diff --check` 通过。
