# 06 — 建立隔离场景并完成最终验收

Parent: [[work-items/report-table-style-boundary/spec]]

**What to build:** 用可持续复查的 Dumi 隔离场景和真实浏览器验收，证明严格边界、双实例 overlay、自动加载及视觉等价同时成立。

**Blocked by:** [[05-移除CSS-Modules双轨并建立边界测试]]

**Status:** ready-for-agent

## Scope

- 建立一个持久 Dumi 隔离场景，同屏放置外部 Handsontable、普通 Ant Design 控件和两个报表实例。
- 两个报表实例分别触发 Ant Design 弹层、Handsontable 菜单、筛选弹窗或可达的代表性 portal，并展示独立 overlay 归属。
- 场景支持卸载/重挂任一实例，用于验证宿主与子节点清理且另一实例不受影响。
- 使用真实浏览器分别检查设计态、报表预览、数据预览、外部控件和双实例交互；保存必要截图或在 ticket 评论中记录可复核证据。
- 对比迁移前基线，除外部元素不再受报表样式影响外，不接受视觉、定位、焦点或交互变化。
- 不引入 Playwright、Cypress 或新的浏览器测试依赖。

## Acceptance

- [ ] 外部 Handsontable 和普通 Ant Design 控件不被任何报表样式命中或改变。
- [ ] 两个报表实例视觉正常，各自弹层只进入自己的 `.udp-report-table--overlay`。
- [ ] 卸载一个实例后其宿主完全清理，另一实例及外部控件继续正常工作。
- [ ] 设计态、报表预览、数据预览和关键弹层完成真实浏览器操作与截图核对，无非预期差异。
- [ ] 从清洁的生成物状态执行 Dumi dev/build 和包 build 均会自动生成所需第三方样式。
- [ ] 全部报表 `node:test`、TypeScript 检查、包构建、文档构建和 `git diff --check` 通过。
- [ ] ADR、spec、tickets、术语表和版本总览链接完整；最终实施结果追加到本 ticket `Comments`。
