## Comments

### 2026-08-18 实施完成（claimed → resolved）

交付：

- 新增 `packages/@newgrand/udp-report-table/src/print/types.ts`：冻结现有
  `formdata + Grids` 契约类型：
  `PrintFormValue` / `PrintFormData`（单据/主表数据）、`PrintTableRow`（行，兼容对象或 JSON 字符串）、
  `PrintTableGrid`（表体，`id`/`containerId` + `Record`，命名对齐 PrintPlugin/Supcan 契约）、
  `ReportPrintData`（含必填 `templateId`、可选 `businessKey`）。
- 新增 `PrintDataJsonPair`：与 `PrintPlugin.buildPrintDataFromJson(formsdatas, griddatas)`
  输入对结构完全对齐的位置式形态（`formsdatas: Record<string,string>`、
  `griddatas: PrintTableRow[][]`）。组件库不改变该函数语义，仅冻结消费方能产出的输入形态。
- 新增 `packages/@newgrand/udp-report-table/src/print/validate.ts`：
  - `validatePrintData(input) → PrintDataDiagnostics{ok, errors, warnings}`：覆盖数据缺失
    （无 formdata / 无 templateId）与非法结构（grids 非数组、缺 id/containerId、Record 非数组、
    非法行、根非对象），缺失业务主键仅记警告（预览可能未提供）。
  - `serializePrintData(input)`：稳定 JSON 序列化，供契约测试与宿主透传；不引入 pdfmake。
- 公共入口 `src/index.tsx` 仅以 `export type` 导出契约类型，并 `export` 两个值
  （`validatePrintData` / `serializePrintData`）；未新增 `buildPdfMakeDocumentDefinition`，
  未新增任何 pdfmake / Supcan 依赖。

模板标识与业务主键来源（写入类型注释）：

- `templateId`：打印模板标识 = 打印设计 id（`printId` / `pageid`），业务应用从打印方案传入，必填；
- `businessKey`：业务主键（`busPhId` / `bizpk` / 批量 `asrCode`），业务应用从当前业务单据传入；
- `formdata` 与 `grids`：单据/表体数据由业务应用装配（对应 `formsdatas` / `griddatas`）。

  非法 grids、id/containerId 变体、非法行、非对象根、序列化契约字面量、无 pdfmake 依赖、
  公共导出）。
