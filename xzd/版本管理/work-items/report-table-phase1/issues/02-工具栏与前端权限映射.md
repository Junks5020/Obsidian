相关：[[../spec]] · [[report-table-ADR-0007-第一阶段权限仅作前端交互控制]]

## Goal

提供 P0 `REPORT_TOOL_BAR_FUNC` 映射，并让 `REPORT_LIMIT` 在工具栏、右键菜单和命令式 API 三个入口保持一致。

## Acceptance

- [x] 覆盖打印设置/预览、撤销/重做、合并、行列操作、导入/导出。
- [x] 覆盖 `FORMULA`、`NON_FORMULA`、`WORKSHEET_ADD_AND_DEL`、`ROW_CLO_ADD`（必要时兼容 `ROW_COL_ADD` 别名）。
- [x] `readOnly` / `isView` 作为总开关，不能绕过细粒度限制。
- [x] 未确认的工具栏常量不创建空壳实现。
- [x] 权限和映射有 node:test 边界测试。

## Comments

### 2026-08-18 实施完成（claimed → resolved，含 code-review 后的三入口收口）

交付：

- 新增 `packages/@newgrand/udp-report-table/src/api/reportLimit.ts`（纯模块，无真实 Handsontable / udp-ui 依赖）：
  - `REPORT_TOOL_BAR_FUNC`：P0 常量 → 设计器实际动作 id 列表（PRINT_SETTING→print_setting、
    PRINT_PREVIEW→print_preview/ribbon_preview、UNDO/REDO、CELL_MERGE→merge_cells/custom_merge、
    ROW_INSERT/COL_INSERT/ROW_DELETE/COL_DELETE→工具栏 insert_*/remove_* 与右键 row_above_X 等、
    ROW_HEIGHT/COL_WIDTH→set_row_height/cus_height 等、IMPORT/EXPORT→report_import/print_import 等）。
  - `resolveToolBarFunc`：未确认常量（NEW_REPORT、SAVE_AS、FIND、REPLACE、CALCULATOR 等）返回 undefined，不建空壳。
  - `ReportLimit` / `ReportLimitKey` / `ReportPermission`：FORMULA、NON_FORMULA、WORKSHEET_ADD_AND_DEL、
    ROW_CLO_ADD（`ROW_COL_ADD` 与 `ROW_CLO_ADD` 双向别名同键）。
  - `isReportLimitAllowed` / `isReportMutationAllowed`：键缺省/`true`=允许，显式 `false`=禁用；
    `readOnly`/`isView` 总开关优先，不能被细粒度配置绕过；`isFormulaCell` 识别公式单元格。
- 三入口一致（code-review 暴露的缺口已收口，共用同一门禁）：
  1. **命令式 API**：`createReportTableApi` 增 `getPermission` 源；insert/delete 行列按
     `ROW_CLO_ADD`、公式单元格写操作按 `FORMULA` 门禁，其余变更类按总开关门禁（只读读取不门禁）。
  2. **工具栏**：`cusToolbar` 对结构变更动作（`STRUCTURAL_TOOLBAR_EDIT_IDS`）在
     `isView` 早退之后追加 `ROW_CLO_ADD` 门禁。
  3. **右键菜单**：`customTable/menu/contextMenu.ts` 的插入/删除/隐藏/合并项 `hidden()` 追加
     `canMutateStructure`（ROW_CLO_ADD）或 `canInteract`（总开关）门禁。
  - 提供者：`src/api/reportPermissionProvider.ts`（模块级 getter 注册/读取），
    `DesignReportTable` 挂载时把 `permissionRef`（isView+reportLimit 实时值）注册进去。
- 公共导出：`index.tsx` 增 `REPORT_TOOL_BAR_FUNC`、`resolveToolBarFunc`、
  `isReportLimitAllowed`、`isReportMutationAllowed`、`canExecuteToolBarFunc`、`isFormulaCell`
  （值）与 `ReportLimit`/`ReportLimitKey`/`ReportPermission`/`ReportToolBarFuncKey`（类型）。
