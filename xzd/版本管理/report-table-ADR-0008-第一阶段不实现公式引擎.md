# ADR-0008：第一阶段不实现公式引擎

第一阶段只保证公式相关字段在报表设计数据中的保留、读取和编辑兼容，不实现 `parseExp`、`runExp`、用户函数、公式分析或设计时实时计算。公式实际计算沿用既有打印/预览链路，完整公式引擎待真实业务调用样例和计算契约明确后单独立项。

## Consequences

- 保存、导入导出和组件重构不得丢失或擅自改写公式字段。
- 第一阶段验收只验证公式数据完整性，不把实时计算结果作为前端组件能力承诺。
- 打印/预览若依赖服务端或 Supcan 计算，必须在联调记录中单独标明计算来源和失败状态。
