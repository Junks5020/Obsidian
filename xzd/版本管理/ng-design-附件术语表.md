# ng-design 附件术语表

记录 `ng-design` 附件组件共享的业务语言与权限概念。

相关：[[00-版本总览]] · [[ng-design-ADR-0001-附件权限分类块透传]]

## Language

**现代附件**：由 React 现代附件组件渲染的附件区域，包括表格附件、表单附件、标签附件和图片附件模式；不包含旧版 `openOldAttachment` 弹窗。

**附件分类**：现代附件按业务来源划分的五个类别——单据附件、审批前附件、审批后附件、来源单据附件、工作流附件。审批前附件是单据附件在单据已审批后的只读呈现，二者共用同一份权限；独立工作流附件弹窗与工作流附件 tab 同属工作流附件分类。

**权限分类上下文**：一次附件操作进行权限判断时采用的完整业务上下文，至少明确附件分类，并在适用时包含当前类型选择及依赖前端状态的判断条件。同一次操作从界面呈现到最终执行必须使用同一份上下文快照。它独立于 UI tab 的具体形态；独立工作流弹窗即使没有工作流 tab，也必须使用工作流附件权限分类。

**分类权限块**：附件初始化接口按附件分类分别返回的权限对象：单据附件（`billAttachButtonRights`）、审批后附件（`approvedAttachButtonRights`）、来源单据附件（`sourceAttachButtonRights`）、工作流附件（`workflowAttachButtonRights`）。是现代附件操作可见性与可用性的唯一业务来源。

**按类型控制**：初始化接口的 `controlByType` 开关；仅作用于单据附件、审批前附件和审批后附件。为真时前两者取 `billAttachTypeButtonRights[typeId]`，审批后取 `approvedAttachTypeButtonRights[typeId]`；来源单据附件与工作流附件始终取各自普通分类权限块，不使用 `typeId`。

**目标类型约束**：单据附件、审批前附件和审批后附件在存在分类树时，新增或导入附件必须先选中具体类型。未选类型只会令 `canAddToSelectedType` / `canImportToSelectedType` 为假，并由 UI 与 handler 共同拒绝；它不改写分类权限块的 `add` / `imp` 原值。来源单据附件与工作流附件不受该约束影响。

**权限数值语义**：权限块内各按钮取值的统一含义——0 置灰禁用、1 可用、2 隐藏；由后端按用户权限返回，前端原样透传，不做覆盖。

**统一按钮权限**：`unifyButtonRights`（及按类型形式 `typeButtonRights`），后端为兼容旧版本前端而保留的冗余字段；新版现代附件不读取。

**前端权限覆盖参数**：`btn`、`permission`、`downloadAttachment` 及 URL `btn*` 参数等曾用于直接改写现代附件按钮权限的兼容入口。新版现代附件保留其公开声明但不读取，不能放宽或收紧分类权限块返回的授权。

**附件可见性**：当前权限分类上下文中的结构性 `visible` 开关，只控制当前分类的内容区域；只有值为 1 时显示，值为 0 或 2 时均保留 tab 导航但隐藏 toolbar、列表及交互区，不模拟“整个内容区置灰”，也不自动切换分类。tab 显隐仍由审批状态与数据存在决定；分类树模式未选中类型时，任一类型可见即保持内容区域可见。

**权限初始化状态**：现代附件初始化权限时的显式三态。`pending` 表示结果未知，必须撤销上一轮权限和内容；`ready` 表示接口成功，分类块是否存在由 fail-closed 规则另行处理；`failed` 表示网络异常、接口失败或响应不可解析，整个现代附件区域不渲染。分类块缺失不属于初始化失败。

**本地上传**：通过按钮、拖拽、粘贴或图片选择进入附件的文件上传路径，由当前分类权限块中的 `add` 控制。

**撤销临时上传**：移除当前会话中尚未保存（`asrFlag=0`）附件的前端派生能力。仅当当前分类允许新增且所选内容全部为未保存附件时成立；它不等同于删除已保存附件，也不改写分类权限块的 `delete` 原值。

**标签附件删除保护**：标签附件删除已通过当前分类 `delete=1` 授权后执行的单条记录约束。单据未审批时允许删除；单据已审批时仅允许删除记录自身标记为审批后的附件。它只收紧后端授权，不会把 0/2 提升为可用。

**共享导入**：将他人共享的附件引入当前附件区域的操作，由当前分类权限块中的 `imp` 控制；它不等同于本地上传。

**下载前业务校验**：后端分类权限允许下载后，由业务方在实际下载或打包下载前执行的附加校验。它只能取消本次操作，不能授予后端已拒绝的下载权限，也不是附件权限来源。
