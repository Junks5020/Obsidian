# ADR-0006：第一阶段采用最小兼容 API 集

第一阶段只实现报表格式设计和打印数据交付 P0 场景实际需要的硕正 API 兼容集合：基础行列/单元格操作、合并与选区、工作表读取、工具栏映射和细粒度权限。打印引擎和现有 PrintPlugin 公共 API 不作为本阶段必做能力；公式引擎、原生事件锁、完整工作表管理、查找替换和用户函数等保留为未支持，待真实业务调用样例出现后再立项。

## Consequences

- 第一阶段可以围绕可验收的 P0 使用场景控制 API 和测试范围。
- 未支持 API 必须在类型、运行时导出和接入清单中明确标记，不能用 Handsontable 内部能力冒充兼容完成。
- 后续新增 API 需要真实业务调用样例和独立验收，不因“原生 API 清单存在”自动进入范围。
