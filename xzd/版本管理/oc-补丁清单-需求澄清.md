# OC 补丁清单需求澄清

本笔记记录“应用管理 > 补丁清单”的原始需求、代码事实与逐项待确认问题；访谈达成共同理解前，不视为实施规格。

相关：[[oc-术语表]] · [[00-版本总览]]

## 用户提出的需求

- 在“应用管理”下新增菜单“补丁清单”。
- 分页展示当前产品线、产品线版本已发布的补丁，按发布时间倒序排列。
- 客户产品线为 i8 或 i8i 且版本为 7.0 及以后时，使用 i8pro 产品线的补丁；版本早于 7.0 时，使用客户自身产品线的补丁。发布平台提供接口。
- 支持按补丁标题、编号、问题描述模糊搜索；按严重程度精确搜索。
- 用户提供了补丁列表和补丁详情两张 UI 参考图。

## 已核对的代码事实

- `route.ts` 中“应用管理”目前只有“服务”子菜单。
- `src/pages/application/useEnvScope.ts` 为应用管理页面加载已完成部署环境，并默认选中首个环境；环境标签由产品线、版本和命名空间组成。
- `OpsEnvVo` 在 `src/services/application/index.tsx` 中包含 `product`、`version` 和环境 `id`。服务页以所选环境的 `id` 请求数据。
- 本仓库没有发现 `oc` 专属术语表、Agent 工作流配置或补丁清单 ADR；共享索引为 [[00-版本总览]]。

## 已确认决策

- 补丁清单的“当前产品线、产品线版本”来自用户当前选中的部署环境；有多个部署环境时由用户选择一个。该选择决定补丁清单的查询上下文。
- 补丁的“应用状态”针对当前选中的部署环境；同一补丁在不同环境可以有不同状态。
- 按用户“可以”确认：清单接口现有状态值为 0 待更新、1 已应用、2 已忽略；采用这三态，不在前端另造“部分应用”状态。
- 按用户“可以”确认：补丁接口按当前选中的部署环境返回应用状态；前端只展示。
- 按用户“同意”确认：首版只包含补丁清单与详情查看，不包含忽略、取消忽略或应用补丁操作。
- 按用户“可以”确认：i8/i8i 7.0 及以上映射到 i8pro 的规则由补丁接口后端按 `deployInfoId` 执行，前端只传部署环境。
- 按上下文将用户回复“事”理解为肯定：i8/i8i 以外的产品线无论版本，都使用自身产品线的补丁。
- 按用户“可以”确认：i8/i8i 的版本按数值比较；`7.0.1`、`7.1`、`8.0` 均映射到 i8pro，`6.9.x` 使用自身产品线补丁。
- 按用户“可以”确认：`7.0-dev`、`7.0-beta` 等版本按数值核心部分识别为 7.0 及以上，映射到 i8pro。
- 按用户“同意”确认：版本比较兼容可选的 `V`/`v` 前缀，如 `V7.0`。
- 按用户“同意”确认：首版详情不展示接口未提供的“关联发版/发布渠道”，也不从当前部署环境推测该信息。
- 按用户“同意”确认：镜像详情显示 `currentTag → patchTag`；`currentTag` 为空时显示“未部署”。
- 按用户“同意”确认：详情有镜像依赖时展示依赖镜像、最低版本和依赖原因；无依赖时不显示依赖区域。
- 按用户“同意”确认：关键词与严重程度同时填写时采用 AND 组合，结果需同时满足两项条件。
- 按用户“同意”确认：关键词或严重程度变化后，分页重置到第一页。

## 接口文档核对

用户提供的 `运维平台-应用(补丁)和配置中心-API文档.html`（`C:\\Users\\jinxu\\Documents\\WXWork\\1688855523837174\\Cache\\File\\2026-09\\运维平台-应用(补丁)和配置中心-API文档.html`）包含补丁清单与详情接口：

- 清单：`GET /api/ng/deploy/patch/list`；必传 `deployInfoId`，可传 `keyword`（编号/标题/问题描述任一命中）、`severity`（精确筛选）、`pageNum` / `pageSize`；返回分页结构并按发布时间倒序。
- 分页结构为 `list`、`pageNum`、`pageSize`、`totalCnt`；默认每页 10，`pageSize > 100` 时会回到默认值 10。
- 严重程度值：0 一般、1 重要、2 严重。
- 清单 `applyStatus` 定义为 0 待更新、1 已应用、2 已忽略，没有“部分应用”状态；用户确认按接口三态展示，不在前端另造状态。详情接口会返回各镜像的 `currentTag` 与 `patchTag`。
- 详情：`GET /api/ng/deploy/patch/{patchCode}?deployInfoId=...`，包含补丁基本信息和镜像列表。
- 文档称补丁包由发布平台导出后导入运维平台，当前页面接口读取运维平台本地表；用户提供该接口文档作为本需求接口参考。
