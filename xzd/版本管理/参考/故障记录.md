# Bug Records

## 2026-07-29 - Attachment source popup could be empty

- Severity: P2
- Symptom: The deployed custom-form attachment popup showed its title and cancel action but no “拍照” source, while the local docs page displayed it.
- Root cause: `AttachmentUpload` resolved only array-valued source IDs; scalar values and empty or wholly invalid arrays could produce an empty source list.
- Fix: Normalize scalar and array configuration, resolve source IDs and MIME values, deduplicate matches, and fall back to all sources when no configured value is valid.
- Regression checks: Six resolver tests passed, changed TS/TSX files passed esbuild compilation, and the local custom-form popup contained one “拍照” button.

## 2026-07-29 - Tree preview sibling filters contained only the first row

- Severity: P2
- Symptom: In design preview, a filter popup on a non-tree column contained only the first row even though the tree-expanded response contained values for the entire column.
- Root cause: The API returned the tree header range as `expand: "down"` with the complete end row, while sibling headers used `expand: "none"` with `from === to`; the frontend normalization required equal `expand` values and therefore never found the authoritative tree range.
- Fix: Treat non-horizontal `"down"` and `"none"` headers as one vertical block, require a real `"down"` tree peer plus expanded target-column data, and extend only the truncated sibling range. Clear stale filter state when refreshed sheet data replaces its rows.
- Regression checks: Real-response-shaped range tests, tree collapse/schema/first-render tests, Prettier, source ESLint, production build, and browser verification on report `2430000000000008`; `bill_name` included values from collapsed descendants and grouped `4.14` as two rows.

## 2026-07-27 - Umi dev compile temporarily could not resolve plugin-model

- Severity: P1
- Symptom: The development overlay reported `Can't resolve '@@/plugin-model'` from the nested `@newgrand/udp-core` package.
- Root cause: The running Umi development compiler had an inconsistent generated-module state. The `@@/*` alias correctly targets `src/.umi/*`, and a clean Umi preparation regenerated `src/.umi/plugin-model` without dependency or source changes.
- Fix: Restart the development process and let Umi finish a single clean preparation/compile cycle; do not patch the package import or add a duplicate alias.
- Regression checks: `npm run build` succeeded, a cold `npm run dev` compiled 9,526 modules, the development server returned HTTP 200, and both stdout/stderr were clear of `plugin-model` resolution errors.

## 2026-07-24 - Explicit cell line breaks collapsed in print design

- Severity: P2
- Symptom: Multiline cell text rendered on one line in print design while preview rendered all lines.
- Root cause: Design-only `white-space: nowrap` rules collapsed newline characters in both direct and nested text render paths.
- Fix: Use `white-space: pre` in the default design render paths; retain `pre-wrap` for the explicit wrap option.
- Regression checks: Direct cells, merged/frozen cells, long single-line text, explicit wrapping, save/reload, and preview parity.
