# Debugging Blind Spots

## Docs and deployed metadata shapes can differ

- A docs page can exercise the expected metadata shape while a deployed service supplies an empty array, a scalar, or stale values.
- Compare the runtime DOM and metadata path, then keep shared components tolerant of supported legacy shapes instead of assuming docs parity proves production parity.

## Generated framework modules

- A development overlay can reflect a stale or incomplete generated-module state even when application source and dependencies are valid.
- Require both a cold production build and a cold development compile before treating a missing `@@/*` module as a source or dependency defect.

## Synthetic response fixtures

- A fixture can preserve the intended meaning while missing protocol-level values that control the actual branch, such as `"down"` on the expanding tree column versus `"none"` on its siblings.
- Before accepting a range or metadata fix, capture the real endpoint response and make the regression fixture preserve its discriminating fields.

## Broad feature removals

- Separate feature-specific state and handlers from shared rendering and lifecycle invariants before deleting a large component block.
- Compare pre-removal and post-removal behavior for virtualization, ref ownership, global registries, detached portals, and metadata hooks.
- When synchronizing fixes across branches, preserve branch-specific children and data arguments instead of applying the original patch verbatim.
- Add regression assertions for both absence of the removed feature and presence of every independent behavior that must remain.

## Design-to-runtime configuration adapters

- Object spreading does not make similar design-time and runtime field names compatible; inspect both schemas before debugging a downstream empty-value filter.
- Exercise serialized design configuration through the fallback path, then assert the final request payload rather than only an intermediate adapter object.
- Treat an explicitly stored `null` as a distinct state from an absent property when applying backward-compatible defaults.
- 为兼容重命名或派生字段时，应分别测试属性缺失与显式 `undefined`、`null`、空字符串、`0`、`false`。
- 对右侧表单编辑左侧表格行的界面，应测试保存时表单值比选中行缓存更新的场景。
