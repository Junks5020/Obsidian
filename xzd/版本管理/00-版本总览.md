# XZD 版本总览

## 使用规则

1. 每个已发布、维护中或准备同步的版本在下表登记一次。
2. 每次缺陷修复或需求完成 Git 提交后，先创建一条[[模板/变更记录模板|变更记录]]，再更新[[01-版本覆盖矩阵|版本覆盖矩阵]]。
3. 覆盖矩阵中的状态只使用：`已同步`、`待同步`、`不适用`、`验证中`、`回退`。
4. 仅当代码已合入该版本对应分支时标记为`已同步`；仅 cherry-pick 或合并完成但未验证时标记为`验证中`。
