# ADR-0007：第一阶段权限仅作前端交互控制

第一阶段的 `REPORT_LIMIT` 只负责前端交互控制：同步约束工具栏、右键菜单和组件 API 的可用性；后端现有鉴权和业务权限仍是最终授权来源。本阶段不新增服务端权限校验，也不把前端限制当作安全边界。

## Consequences

- 同一权限配置必须覆盖工具栏、右键菜单和命令式 API，避免只禁用界面而仍可通过 API 修改。
- 前端联调需要验证服务端拒绝、权限过期和接口错误状态；不能仅凭按钮隐藏判定权限完成。
- 若后续需要服务端细粒度权限，另立后端契约和安全评审，不扩展本 ADR 的范围。
