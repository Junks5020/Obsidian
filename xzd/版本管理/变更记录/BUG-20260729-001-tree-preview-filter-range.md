# BUG-20260729-001：树报表相邻列筛选仅包含第一行

## 问题与修复

- 问题现象：设计预览中，树报表非树列的筛选弹窗只有第一行数据，没有包含该列随树展开产生的全部内容。
- 根因：预览接口将树列表头返回为 `expand: "down"` 和完整范围，而相邻列为 `expand: "none"`、`from === to`；前端补偿逻辑要求两列 `expand` 完全相同，无法找到树列的权威范围。
- 修复内容：将 `"down"` 与 `"none"` 统一识别为纵向连续筛选块；仅在确认同表头、同起点、列连续、存在树单元格且目标列有扩展数据时，使用树列末行修复相邻列范围。刷新 sheet 时同步清除旧筛选行号缓存。
- 影响范围：`report-web` 表格设计预览中的树报表筛选、排序范围及刷新后的筛选状态。
