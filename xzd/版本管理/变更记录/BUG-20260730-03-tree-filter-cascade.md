# BUG-20260730-03：树报表后续筛选未继承前列条件

## 问题与修复

- 问题现象：第一列已筛选后，打开后续列筛选弹窗仍包含已被排除行的值。普通多列筛选可级联，但单列树和父子树字段行为不一致。
- 根因：筛选状态以 `${sheet}-${expand}-${from}_${to}` 分组。树列使用 `expand: "down"`，右侧字段使用 `expand: "none"`；虽然归一化后行范围一致，仍落入不同 `filterRangeMap` 条目，后续弹窗无法读取前列条件。
- 修复内容：在树范围归一化后，以筛选轴生成状态 key。横向筛选保留 `right`，所有纵向筛选统一使用 `down`，让普通多列、单列树和父子树共享已有的多条件筛选逻辑。
- 影响范围：报表设计预览的纵向多列筛选、单列树和父子树右侧字段筛选；横向筛选保持独立。
