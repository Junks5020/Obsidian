# R-260702-000017：报表查询条件支持用户自行配置隐藏/显示

## 需求与当前进度

- 需求目标：设计端可配置查询条件默认隐藏；正式运行态允许操作员调整手动输入查询条件的显隐，并按操作员和报表持久化。
- 当前状态：前端实现、失败链路验证及审查问题修复已完成，已在 `6.5.2-dev` 形成来源 Commit；成功持久化链路仍被后端 `saveReportQueryConfig` 的 500 响应阻塞。`6.5.2` 与 `ljx-7.0` 仅登记为后续同步目标，本次未执行同步。
- 设计预览边界：没有 URL `reportId` 的设计器临时预览也展示齿轮入口，配置只应用于当前预览会话；正式运行态携带 `reportId` 时通过接口持久化个人偏好。

## 已完成实现

- 设计端查询条件 `widgetSetting` 增加 `hidden`，约定 `0` 显示、`1` 隐藏，存量缺失值按显示处理。
- 必填条件和被当前可见条件作为变量过滤源引用的条件强制显示，并在设计端与运行态设置弹窗中禁用关闭。
- 运行态查询区增加设置入口和“查询条件设置”弹窗，仅列出手动输入条件，展示名称、控件类型及“必填”“引用源”状态。
- 隐藏条件不渲染到查询区，不使用默认值，也不参与查询和导出过滤参数；会话内重新显示时可恢复此前输入值。
- 读取个人配置失败时回退报表设计详情中的 `querySetting`，避免预览初始化被异常中断。
- 保存请求使用 `reportId`、`sheetKey`、`layoutType: 1` 和序列化 `layout`；保存失败时保留弹窗与原查询区，并提示“保存失败，请重试”。
- 个人偏好优先按条件 `id` 匹配；接口未提供 ID 的存量数据退化为参数名和数据集组合匹配。
- 设计预览直接使用观察者传入的 `querySetting`，不使用空 `reportId` 请求个性化接口；确认后更新当前预览，取消不改变查询区。
- 当前 sheet 的手动条件全部隐藏后仍保留齿轮入口，用户可以重新显示条件。
- 同一个设计条件映射到多个数据集时，设置弹窗按逻辑条件合并为一个显隐开关，确认后原子同步到所有映射；用于分组的临时字段不会进入持久化数据。
- 当前 sheet 没有可见手动条件但仍有系统参数时，工具栏保留查询动作，确保用户能够清除旧条件并重新请求报表数据。

## 问题复盘与经验沉淀

### BUG-20260730-04：设计预览缺少查询显隐设置入口（P2）

- 现象：从设计器进入预览后能看到查询条件，但没有设置齿轮，无法调整显隐。
- 根因：预览组件把 URL `reportId` 同时当作后端持久化能力和 UI 入口的判断条件；设计预览由观察者草稿数据驱动，本来就没有 URL 报表 ID。
- 修复：将“是否展示设置入口”和“是否可远程持久化”拆分；设计预览按会话应用，正式运行态按接口保存；所有条件隐藏后仍保留恢复入口。
- 验证：单元测试及浏览器覆盖齿轮入口、弹窗内容、本地确认、全部隐藏后恢复、重新显示和取消不变；Prettier 与 `git diff --check` 通过。

### BUG-20260731-03：多数据集映射被拆成独立显隐开关（P1）

- 现象：一个逻辑查询条件映射多个数据集时，在设置弹窗中出现多行，并可能只隐藏报表的一部分数据集过滤。
- 根因：设计预览把 `paramKey` 数组展开为运行态项时丢失了共同的条件身份。
- 修复：展开时保留临时来源分组键；弹窗优先按该键或持久化条件 ID 分组；一次显隐选择同步回全部映射，并在保存前移除临时元数据。禁止仅按显示名称合并无关条件。
- 验证：聚焦测试覆盖临时分组、持久化 ID、同名无关条件、同步输出及临时字段移除；生产构建通过。

### BUG-20260731-04：全部手动条件隐藏后缺少可用查询动作（P2）

- 现象：隐藏全部可选手动条件后，如果仍有系统参数，查询面板只剩设置齿轮，工具栏查询动作也被隐藏，旧过滤结果无法立即清除。
- 根因：工具栏按查询项总数判断是否展示查询动作，没有区分系统参数与用户可编辑条件。
- 修复：只要不存在手动输入条件就展示工具栏查询动作，包括空查询项和仅系统参数两种状态。
- 验证：聚焦测试覆盖空列表、仅系统参数、仅手动条件及混合条件；生产构建通过。

### 防回归规则

- UI 能力与持久化能力必须分别建模：入口是否展示、初始数据来源、确认后写服务端还是仅更新会话，是三个独立决策。
- 设计预览可能以观察者或草稿数据为权威来源；缺少运行态持久化 ID 不代表界面能力不可用。
- 一个设计配置展开为多个运行态项后，按条件配置的功能仍须保持逻辑身份，并对所有映射原子应用。
- 当所有可配置字段都能被隐藏时，必须保留恢复入口；同时分别验证有、无系统参数时仍存在可执行的查询动作。
- 会话预览和正式运行态均需分别验证确认与取消，且确认后不得让临时分组字段进入持久化数据。
