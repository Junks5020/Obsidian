# 07 — 受控 Agent 上下文

相关：[[../spec]] · [[../试点方案]]

**What to build:** 「发给 Agent」先预览将发送的字段与模型服务商，用户只发送所选标的或主动选择的全局摘要；默认不含账户名与券商名，采用账户匿名标签；用户未发送时 Agent 无法读取账本，发送后的草稿作为会话输入持久记录、可从会话日志重建。

**Blocked by:** 02, 06

**Status:** in-progress — 依赖 02、06 均已 implemented（2026-09-28 解除阻塞）。

- [ ] 发送前预览将发送的字段与模型服务商，用户审阅后才发送
- [ ] 用户可只发送所选标的，或主动选择发送全局摘要
- [ ] 默认不含账户名、券商名，使用账户匿名标签
- [ ] 用户未发送时 Agent 无法读取账本（插件不提供绕过用户选择的账本读写工具）

- [ ] 模型侧不存在绕过用户选择的账本读取路径
