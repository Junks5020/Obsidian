# 国内行情供应商对照（阶段 0）

相关：[[../work-items/stock-workbench/试点方案]] · [[../work-items/stock-workbench/issues/05-market-data-provider-adapter]] · [[2026-09-08-现有股票DSH插件功能调研]] · [[../00-deepseek-harness索引]]

本笔记只对照**有程序化接口、可向供应商购买或申请试用**的国内数据源。不等于推荐、已获许可或可接入试点生产。公开网页抓取、券商交易通道、同花顺终端抓取均不进入候选。

试点准入门槛见 [[../work-items/stock-workbench/试点方案#行情供应商准入门槛]]：书面允许本地私有使用；A 股与港股的搜索、最新价、日/周 K、行业、基本面、新闻或公告元数据、HKD/CNY；稳定 API 与频率；不把持仓回传供应商；本机可保存并轮换 Key。

## 与本项目最接近的机构终端 API

客户若已有同花顺、Choice 或 Wind 账号，优先向该家要试用 Key 与书面条款，不要另开公开网页源。

| 供应商 | 第一方已确认 | 对本项目的缺口 | 接入形态 |
| --- | --- | --- | --- |
| 同花顺 iFinD 数据接口 | 官方称覆盖实时与历史行情、基本资料、财务、多市场；HTTP `refresh_token` / `access_token`；示例代码含 `000001.SZ` 与 `00700.HK`；FAQ 写明日行情入库时间（A 股约 15:07、港股约 16:37）与 HTTP 可绑 20 个 IP。 | 须向销售确认：盘中最新价能否满足 15 秒刷新、新闻/公告元数据、行业、HKD/CNY、私有 DSH 插件再分发/本地使用条款、最小套餐。 | HTTP 适合本机 Host；SDK 单设备登录限制更严。客户已使用同花顺环境。 |
| 东方财富 Choice 量化接口 | 官方数据中心称覆盖沪深与港股，含基础信息、公告、财务；用户手册写明量化接口覆盖港交所等，含行情、财报、资讯。 | 须确认：价格/K 线延迟、搜索/行业/汇率、Web 插件使用许可、是否必须常驻 Choice 终端、年费。 | 常见路径是 `EmQuantAPI` SDK + 账号激活，不是纯 HTTP Token。 |
| 万得 Wind | Client API 官方页称可在桌面第三方应用中访问中港美基本面、行情、历史日线/分钟/Tick；另有面向企业的数据接口服务（API 网关）。 | 个人/试点预算通常最高；Client API 往往依赖本机 Wind 终端；企业网关才接近独立 HTTP。须确认私有插件条款与 HKD/CNY、资讯字段。 | 终端旁路 SDK，或企业 API。 |

## 明确不进入阶段 0 候选

| 类型 | 例子 | 原因 |
| --- | --- | --- |
| 公开网页/爬虫库 | 新浪、腾讯、东方财富网页、雪球网页、AKShare、efinance | 试点方案禁止未获书面允许的公开网页接口作为生产依赖。 |
| 券商交易终端 API | MiniQMT / xtquant、富途 OpenAPI、券商柜台 | 规格排除对接券商、下单、读取实时账户；QMT 还要求本机交易客户端。 |
| 交易所直连行情 | 上交所/深交所 Level-1/2、港交所 Market Data | 面向持牌转发商，不是单机插件可购的零售 HTTP。 |
| 未核验牌照的聚合行情 | AllTick 等境外 Token 行情 | 官方称覆盖 A/港报价与 K 线，但公司主体与交易所转发授权未在本笔记核验；且基本面/新闻通常缺失。 |

来源：[迅投 xtdata](https://dict.thinktrader.net/nativeApi/xtdata.html)、[AllTick Stock API](https://alltick.co/zh-CN/products/stock-api)、[[../work-items/stock-workbench/spec]] Out of Scope。

## 阶段 0 建议问法

1. 客户现有是否已采购 Wind、Choice 或 iFinD。有则只谈那一家的插件使用权与字段。
2. 若只有同花顺看盘、没有数据接口：向同花顺要 **iFinD HTTP** 试用，核对 15 秒报价、港股、新闻公告、汇率、本地私有使用。
3. 若只要低成本验证字段：可把 Tushare 实时日线 + 公告包当**对照样本**，不能替代书面许可。
4. 2026-09-17：私有试点选定独立实现的东方财富公开 JSON，不接腾讯热备、券商或 Tushare。公开网页源的条款风险由试点接受；第二家付费供应商仍须书面确认。
