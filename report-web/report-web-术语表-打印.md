# 报表打印

报表打印包含使用打印模板和不使用打印模板的预览与输出，以及操作员个人打印偏好的管理。

## 打印场景

**有模板打印**：以选定打印模板作为排版依据的打印场景，个人打印偏好归属于操作员与该模板。
_Avoid_：无模板打印

**无模板打印**：不选用打印模板、直接依据业务表单内容进行打印的场景，个人打印偏好归属于操作员与该业务表单。
_Avoid_：空模板打印

## 设置与格式

**打印设置**：决定打印输出的页面、页边距、分页和页眉页脚的全部参数。
_Avoid_：列宽行高格式、查询条件

**个人打印设置**：操作员主动保存、供以后使用同一打印模板或业务表单时沿用的打印偏好，不等同于本次预览中尚未保存的调整。
_Avoid_：模板设计设置、临时打印设置

**默认打印设置**：没有个人打印偏好时采用的模板打印设置，包括模板设计者规定的参数及未规定部分的系统默认参数。
_Avoid_：个人打印设置、统一空白设置

**列宽行高格式**：业务表单各列宽度与各行高度的排版偏好，属于无模板打印保存与恢复的内容，但不等同于打印设置。
_Avoid_：打印设置
