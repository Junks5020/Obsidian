# 报表订阅

报表订阅是在指定时间按固定查询口径计算报表，并向接收方推送计算结果的业务能力。

## 订阅与执行

**订阅方案**：关联一个报表的定时计算与结果推送配置，包含计算计划、计算参数、结果命名规则和推送对象。一个报表可以拥有多个订阅方案。
_Avoid_：事件订阅、报表结果

**参数映射**：订阅方案中某个工作表查询条件与执行时参数值之间的对应关系。跨工作表共享的查询条件只配置一次，对各工作表生效。
_Avoid_：查询默认值

**接收方**：接收订阅结果的操作员或角色。角色代表执行时属于该角色的所有有效操作员，不等同于固定的操作员名单。
_Avoid_：员工、联系人

**运行日志**：一次订阅执行面向一个接收操作员的执行记录，状态为成功、失败、部分成功或跳过。
_Avoid_：订阅方案、订阅结果

**订阅结果**：订阅方案执行后生成的报表计算结果，其名称由方案的结果命名规则确定。
_Avoid_：订阅方案、当前实时查询结果
