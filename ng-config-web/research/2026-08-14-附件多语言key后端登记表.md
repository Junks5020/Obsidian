# 附件相关页面多语言 key 后端登记表

相关：[[00-ng-config-web索引]] · [[2026-08-14-附件多语言key清单]]

> 用途：供后端在平台语言字典中登记以下 key 的中英文文案。登记完成后，前端经 `SUP/GetLanguageInfoByBusType` / `SUP/Language/getLanguageMap?identity=xxx` 下发覆盖生效；未登记期间前端由中文兜底。
>
> 登记范围说明：
> - 按归属页面分组，**附件存储配置页（busType `16780`）与附件数据迁移页（busType `16781`）共享 `getCommonConfig` 字段**，存储页「二」的全部 key 需在 `16781` 下同样登记（数据迁移页源库无前缀、目标库 `target_` 前缀共用同一批 langKey）。
> - **通用 key（`requestFail`、`btnSave`、`saveSuccess`、`apiFail`、`enterpriseInfo` 等）可能已在平台语言包登记，请先查重再登记**，避免重复 key 互相覆盖。
> - 附件预览页无 busType，按页面 identity 走 `getLanguageMap` 下发，具体 identity 请与前端/平台确认。
