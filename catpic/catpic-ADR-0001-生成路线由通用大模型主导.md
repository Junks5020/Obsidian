# ADR-0001：生成路线由通用大模型主导，"对齐"定义为语义级

宠物动漫画要求「只换风格、不改内容」。最初提出的是逐像素结构对齐（C 档），但逐像素一致性依赖更强的结构条件控制（ControlNet / LoRA 类管线），这类方案需要自建生成管线、逐风格准备适配权重，与「主要使用 AI 大模型做替换」的出发点冲突，且引入持续运维成本。

决定：**生成能力以通用多模态 image-edit 大模型为主导**；「对齐」定义为**语义级结构对齐 + 主体一致**，不承担逐像素一致的承诺。结构条件控制类管线保留为退路，本期不实施。

相关：[[catpic-术语表]] · [[00-catpic索引]] · [[catpic-ADR-0002-平台骨架先行生成能力以适配器保留]]

## 考虑过的选项

- **C1 自建结构条件控制管线**：结构与风格更可控，但需自备推理环境与逐风格调优，运维重。**本期不研究自建生成管线。**
- **C2 大模型 image-edit 主导**（采纳）：零运维、换风格只改提示词模板、立刻能上；代价是细节会漂移，部分产出需要重试或人工兜底。
- **C3 混合（大模型生成 + 结构回贴）**：效果可能更好，工程最重，MVP 阶段不碰。

## 后果

- **候选验收指标（阈值待实测后确定，不是已确认的验收口径）**：主体轮廓 IoU、姿态关键点一致性、"同一只宠物"人眼通过率。没有可测替代指标的的话，语义级对齐会退化成主观争论。
- 产物会有一定比例的失败/不合格，**重试与人工兜底是产品的一部分，不是异常分支**。
- 风格只能是 prompt 模板级的东西，不能指望产出严格可复现。
- 需求文档与验收口径中不再出现"逐像素"一词。
