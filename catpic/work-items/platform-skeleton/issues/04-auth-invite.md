# 04 邮箱 OTP 登录与邀请码兑换

Status: todo
Blocked by: 01, 02

相关：[[../spec]]

## 目标

邀请制用户能可靠地登录，并把邀请码兑换成额度。

## 范围

- `/login`：邮箱 + 6 位验证码（不使用 magic link 跳转）
- 邀请码输入内嵌本页，调用 `redeem_invite`
- 未登录访问受保护页面 → 重定向登录

## 验收

- 用 QQ 邮箱与 163 邮箱各实测一次真实投递，记录结果与耗时
- 若 Supabase 自带邮件不满足，记录结论并决定是否配置自有 SMTP（不在本任务内实施）
- 已兑换的邀请码再次输入 → 明确报错，不重复加额度
- 未登录访问 `/` 与 `/g/[id]` → 跳转登录
