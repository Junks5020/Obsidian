# 05 生成能力适配器与占位实现

Status: todo
Blocked by: 01, 03

相关：[[../spec]] · [[../../catpic-ADR-0001-生成路线由通用大模型主导]] · [[../../catpic-ADR-0002-平台骨架先行生成能力以适配器保留]]

## 目标

把「生成能力」收敛成一个接口，并提供一个占位实现，使产品流程可以完整跑通。

## 范围

- 适配器接口：输入为原图引用 + 风格，输出为定稿引用 + 结果元信息
- 占位实现：基于用户原图的确定性滤镜（边缘/降饱和/色阶），同一输入同一风格必须产出相同结果
- 产品代码不得直接 import 任何模型 SDK
- 输出需带「占位效果」标识字段，供下游四处展示使用

## 不做

- 不接真实模型，不评估模型质量
- 不做强度档

## 验收

- 同一输入 + 同一风格重复生成 → 产物一致
- 全仓库 grep 不到任何模型 SDK 的直接引用
- 占位标识可被任务页、历史、分享页、OG、下载文件名读取
