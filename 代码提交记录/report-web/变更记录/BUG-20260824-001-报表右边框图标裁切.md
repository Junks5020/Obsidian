# BUG-20260824-001 报表右边框图标裁切

## 问题或需求

- 请求或现象：报表设计器边框菜单中的“右边框”图标右侧实线显示不完整。
- 根因：`BorderRight` 的实线在嵌套 SVG 平移后落在 `x=15.5..16.5`，超出 `16x16` 视口；根 SVG 的 `overflow: hidden` 裁切了右侧部分线条。
- 修复或实现：将实线 polygon 从 `x=15..16` 左移至 `x=14..15`，平移后的实际范围为 `x=14.5..15.5`，完整保留在视口内。
- 影响范围：仅报表设计器工具栏边框菜单与选中后的右边框图标视觉呈现；不改变边框命令行为。
