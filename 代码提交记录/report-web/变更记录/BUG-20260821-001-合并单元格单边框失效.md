# BUG-20260821-001 合并单元格单边框失效

## 问题或需求

- 请求或现象：单元格合并后，设置上边框或下边框看起来不生效；同一分支也影响左、右单边框。
- 根因：合并分支把主单元格坐标构造为 `[startRow, startRow]`，当起始行列不同时会把边框写到其他物理单元格；行列相等时会偶然掩盖问题。
- 修复或实现：使用右下隐藏单元格提供的权威 `mergeParent.row`、`mergeParent.col` 坐标写入单边框，并新增合并四边及非合并对照回归测试。
- 影响范围：报表设计器自定义表格的合并单元格单边框设置；不改变非合并选区的边框范围行为。
