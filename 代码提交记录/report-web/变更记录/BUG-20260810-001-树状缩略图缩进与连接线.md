# BUG-20260810-001 树状缩略图缩进与连接线

## 问题

- 现象：树状报表首列按层级缩进时占用过宽，三级内容明显右移；收紧缩进后，祖先竖线与展开图标中心错位。
- 根因：每级占位固定为 `24px`；收紧为 `16px` 后，祖先竖线仍按占位的 `50%` 定位为 `8px`，与 `24px` 展开占位的 `12px` 中心不一致。
- 修复：每级缩进改为 `16px`，祖先竖线定位改为 `12px`，并新增真实 LESS 编译回归测试验证三级缩进上限与连接线对齐。
- 影响范围：`src/components/report/preview/plugins/treeRender/treeExpandLine/index.less`、`tests/tree-preview-indent.test.ts`。
