# BUG-20260811-001 查询设置默认值保存及传参丢失

## 问题

- 现象：查询设置中最后编辑的默认值可能没有进入 `saveReportDesign` 请求的 `querySetting`；再次进入后没有默认值。后端仅返回 `defaultValue`、未返回运行态 `value` 时，初始查询和导出参数也会漏掉默认值。
- 根因：弹窗确认只校验右侧表单，随后直接读取左侧表格缓存，没有显式提交当前表单值；运行态成功请求路径直接读取 `item.value`，只有设计配置回退路径处理了 `defaultValue`。
- 修复：弹窗确认前把当前表单值提交到选中行；统一运行态取值规则，仅当 `value` 属性不存在时回退到 `defaultValue`，保持 URL 参数最高优先级，并保留显式 `null`、空字符串和 `0`。
- 影响范围：查询设置保存、设计预览、正式运行态初始查询和导出查询参数。
