# BUG-20260822-001 报表打印设置预览方向丢失

## 问题或需求

- 请求或现象：设计页将报表打印方向设置为横向并点击预览后，预览页打印设置恢复为纵向。
- 根因：设计态打印配置先前未完整进入保存/预览请求；补齐请求后，设计预览返回的 sheets 又未把顶层 `printSetting` 注入消费者读取的 `globalSettings.printSetting`。
- 修复或实现：保存、设计预览、Excel 导出统一传递序列化打印配置；设计预览按 sheet 注入设置，新预览发布清除旧 sheets，查询刷新保留预览内修改，并过滤非法配置。
- 影响范围：TableManager 报表设计保存、设计预览、预览打印设置及导出链路；独立运行态不受影响。
