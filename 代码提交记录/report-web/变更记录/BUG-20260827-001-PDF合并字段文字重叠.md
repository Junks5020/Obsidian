# BUG-20260827-001 PDF 合并字段文字重叠

## 问题或需求

- 请求或现象：客户导出的“洁能PMS”PDF 中，跨两行、跨九列的长字段值在 50% 缩放和 1.5 行距下自动折成两行，第二行与后续表格行文字重叠。
- 根因：`generateTable` 仅为 `text` 类型执行手动换行。长 `field` 保持 `wrapCount = 1`，rowSpan 中部对齐据此产生单行 `relativePosition.y`；pdfMake 随后又自动折成两行，而 `relativePosition` 不参与表格高度计算，导致第二行越过合并区域。
- 修复或实现：对 `rowSpan > 1` 的文本型动态单元格预先测量并写入显式换行，保留完整字段值，以实际行数和实际行距计算中部/底部对齐偏移；普通字段和既有 `text` 跨页续写保持不变。
- 影响范围：`src/components/report/print/utils/PDF.ts` 的 pdfMake 合并单元格文本排版，以及新增生成级回归测试；不修改客户 PDF、HAR、字体、接口或后端数据。
