# BUG-20261016-001 报表设计器预览消息无法触发页面跳转

## 问题与修复

- 现象：组件库触发 `table_preview` 后发布了预览数据，宿主仍未打开报表预览页。
- 根因：宿主依赖已移除的 `handleToolBarAction` 回调；组件按 `previewReportSchema-<报表ID>` 发布，预览页按报表名称订阅，两侧消息通道不一致。
- 修复：设计页订阅报表 ID 通道，按报表名称转发缓存数据，再打开 `/tableDesign/TableManager/preview`，保留 sheetKey。ID 与名称相同时不再次发布；挂载前清理旧缓存，卸载时取消订阅和待执行跳转。
- 配套：预览标题动态读取业务语言；组件和 UI 依赖升级、锁文件与启动脚本调整在同一提交中交付，本地路径只留在忽略的 `.umirc.local.ts`。
- 影响范围：`src/pages/TableManager/design/index.tsx`、`tests/report-design-preview.test.cjs` 及组件依赖配置。
- 关联需求：同一提交完成 [[REQ-20260902-001-报表多语言配置同步]] 的 7.0 宿主适配；预览消息根因独立于多语言问题。
