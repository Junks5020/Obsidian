# BUG-20260902-001 独立菜单打印设置未生效

## 问题或需求

- 请求或现象：TableManager 设计预览能正确显示保存的打印设置，但把报表配置为独立菜单后，打印设置仍显示默认值，没有使用后端 `printSetting` 字段。
- 根因：设计预览分支会把顶层打印配置注入 `sheets[].globalSettings.printSetting`，独立菜单的 `getReportData` 分支却原样透传每个 sheet 顶层的 `printSetting`；弹窗、打印和 PDF 导出只读取嵌套字段。
- 修复或实现：运行态每次请求都汇总本次后端响应中的顶层 `printSetting`，按 `sheetKey` 注入 `globalSettings.printSetting`，以后端最新值覆盖页面旧值；设计预览保留原有的本地覆盖行为。
- 影响范围：TableManager 带 `rep_id` 的独立菜单运行态、打印设置弹窗、打印和 PDF 导出读取链路。
