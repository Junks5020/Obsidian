# BUG-20260805-001 附件预览底部空白

## 问题

- 现象：附件预览右侧内容下方出现大面积空白，预览区域未填满可用高度。
- 根因：预览布局混用了基于视口的固定高度计算与父容器百分比高度，右侧内容和 iframe 无法稳定占满剩余空间。
- 修复：将左右区域改为纵向 flex 布局，以 `flex: 1` 和 `min-height: 0` 分配剩余高度，并让 iframe 填满内容区域。
- 影响范围：`src/pages/SUP/FilePreview/index.less`；新增 `tests/file-preview-layout.test.cjs`。
