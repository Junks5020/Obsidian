# ng-work-web 意图配置与查单

区分意图配置管理与实际业务数据查询，避免将“智能查单”页面标题误认为业务执行能力。

## 领域语言

**意图配置**：描述查单或问数需求及其关联查询条件、取数方式和展示方式的配置。
_Avoid_：查询结果、业务单据

**意图配置管理**：对查单和问数意图配置进行检索、查看及维护的管理活动；本次讨论的“智能查单”管理页面属于此范围。
_Avoid_：实际查单、业务单据查询

**实际查单**：根据查询条件获取业务单据数据的运行时活动，不等同于检索或查看意图配置。
_Avoid_：意图配置检索

**表单查询意图**：以关联业务类型、取数方法及字段参数为核心进行单据检索的一类意图配置。
_Avoid_：普通查单、业务单据

**问数查询意图**：通过数据集、报表或 BI 看板等分析来源执行统计问数的一类意图配置。
_Avoid_：报表数据、统计结果

**内置意图**：系统预置且不允许用户修改的配置，在管理端只能以只读方式查看。
_Avoid_：默认配置、只读模板

**页面草稿**：正在新增或编辑中的意图配置在当前页面会话内尚未持久化提交的临时状态。
_Avoid_：已生效配置、数据库记录

**落库保存**：将校验通过的意图配置页面草稿正式提交持久化，并使后续管理列表与运行时生效的行为。
_Avoid_：页面暂存、表单填写
