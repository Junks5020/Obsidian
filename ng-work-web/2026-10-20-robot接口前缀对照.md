# robot 接口前缀对照

相关：[[00-ng-work-web索引]]

`micro-apps/robot` 里原先直连各服务的请求，统一加上本仓库网关前缀 `/n-work`。路径段是 `n-work`，与主应用、后台管理已有接口一致，例如 `/n-work/api/Sup/AI/AIModel/getAllDataList`、`/n-work/liuhe/v1/ping`。

开发代理：主应用 `.umirc.ts` 已把 `/n-work` 转到 `http://192.168.8.192:31344`，路径原样转发。robot 独立启动的 `.umirc.ts` 补了同一条代理。

后端下发的页面地址（`functionUrl` 里的编辑、查看链接）没有改。智能审批 `intelligentApproval` 仍返回本地 mock，注释中的地址已同步加前缀。
